# Figure 2. Resource usage per 1,000 adverts

**Figure 2:** API charge and summed request time per 1,000 adverts across all experimental conditions for the {{ dataset_name }} dataset. The left bars show recorded external API charge in US dollars per 1,000 adverts; the right bars show summed saved request time in seconds per 1,000 adverts. Values divide saved totals by all adverts in this dataset and multiply by 1,000. Displayed time values and time SDs are rounded to the nearest second; bar lengths and whiskers retain the original precision. Shorter bars mean lower charge or fewer request-seconds. All completed, pinned configurations with real inference requests are included, including finished runs with recorded failures. Summed request-seconds are not elapsed batch time: concurrent requests overlap. Cached results retain original charges and timings; local external API charge is zero while infrastructure costs are unknown. Published full-collection costs have a different scope.
