# Figure 1. ROC: relevant adverts discovered (TPR) vs. irrelevant adverts sent for review (FPR)

**Figure 1:** Interactive receiver operating characteristic (ROC) depicting the proportion of relevant adverts correctly flagged (true-positive rate, TPR) against the proportion of irrelevant adverts incorrectly flagged for review (false-positive rate, FPR) across all experimental conditions on the {{ dataset_name }} dataset. Higher TPR at the same FPR means more relevant adverts caught without increasing irrelevant review (i.e., top-left represents optimal discrimination). Zero-shot curves use solid lines; few-shot curves use dashed lines. Each curve shows how a probabilistic model balances this trade-off as its decision threshold varies; its round marker shows the default threshold of 0.5. Models that return only binary labels (e.g., chat LLMs) and published baselines reported as aggregate results are represented by single operating points. Random review and 95% TPR reference lines are included for context; the 95% TPR line is not a validated operating threshold. Curves/points can be displayed or hidden via the controls above for clear comparison. Adverts with inference failures are always routed for review; scoring coverage is reported in [Table 1](#table-1).
