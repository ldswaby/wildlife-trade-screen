# Figure 3. Zero-shot results across datasets

**Figure 3:** Inter- and intra-dataset KPI summary statistics. For individual measured models, white circles and whiskers show the arithmetic mean ±1 population standard deviation across the three datasets. For the ‘Decision models (*μ*)’ row, white diamonds and whiskers show the mean and population standard deviation across all nine decision model–dataset values, combining variation between models and datasets. These whiskers describe observed variation, not confidence intervals. Standard deviations for percentage metrics are expressed in percentage points (pp). Coloured dots show individual dataset results for each model, or the mean across the three decision models within each dataset in the ‘Decision models (*μ*)’ row, with fixed vertical offsets. Higher balanced accuracy is better, whereas lower values are better in the other panels. Measured decision/chat model rows include only zero-shot configurations. N/A marks unavailable summaries. The ‘Decision models (*μ*)’ row additionally displays averages across all decision models. (Note that these include `d3`, which runs on limited local hardware with no external API charge, lowering the average API cost and raising the average latency. These resource averages summarise different deployments, and do not represent the cost or latency of a single deployable system.) API charges and summed saved request-seconds are shown per 1,000 adverts. Summed request time is not elapsed batch time under concurrency. For reference, the Supervised baselines row (distinguished by the grey band) shows only the best available published per-dataset baseline by estimated balanced accuracy for each dataset: `ACTL text` for Shark Products and `LTS text` for Animal Products. These are individual reference points, with no pooled mean or SD. Live Birds has no matching published composite-policy baseline, and was instead reported only on the three separate policy tasks described in the [Live Birds Dataset details](#birds-dataset) section. As a potentially useful contextual reference, the equally weighted mean (±1 population SD) balanced accuracy across the best published baselines for each of these tasks is captured by the *‘Live Birds (split policy)’* point (domestic poultry: ~98.05% - Naive Bayes; junk: ~91.3% - Naive Bayes; and wanted adverts: ~87.85% - logistic regression, each derived from rounded 10-fold cross-validation averages in [Stringham et al., 2021, Appendix S2](https://doi.org/10.1371/journal.pone.0254007.s002)).
