The amount of context provided to a model for each advert is likely to influence its screening performance. However, the datasets used here differ in how they capture this context. Both [LTS datasets](https://arxiv.org/html/2504.21211#S4.SS1) (Shark Products and Animal Products) provide advert titles and separate description fields, but descriptions are populated for only 10 Animal Products adverts. Consequently, Animal Products was evaluated using titles only. Live Birds provides only a composite field containing title and description text. The effect of adding descriptions to advert titles could therefore be evaluated only for Shark Products.
